# H10 Simulator Round 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `tool/h10-sim` a first-class UBM tool: full Linux fidelity as a Polar H10 with known identity, JSON device profiles, an authenticated control port, a `peripheral-sim` driver host kind with combined test sequences, CI on Linux+macOS, and docs that ship with the behaviour.

**Architecture:** All GATT behaviour stays in pure-data modules (`sim.rs`, `gatt_spec.rs`, `advertisement.rs`, new `profile.rs`) that are unit-tested without a radio; the `PeripheralRadio` trait gains defaulted methods so the macOS/Windows backend needs no changes; the driver protocol gains one host kind (fail-closed decode already refuses unknown kinds, so old servers refuse the new sim safely under `ubm-test-driver/1`).

**Tech Stack:** Rust (tokio, serde/serde_json, bluer 0.17.4 on Linux, ble-peripheral-rust 0.2.0 elsewhere; new: tokio-tungstenite for the driver client), TypeScript driver (`examples-shared/driver`), GitHub Actions (`ci.yml`), systemd user units.

Profile JSON schema (all fields required except where noted):

```json
{
  "device_information": {
    "manufacturer": "Polar Electro Oy", "model": "H10",
    "serial": "SIM000001", "firmware": "3.2.1", "hardware": "9",
    "software": "3.2.1", "system_id_manufacturer": 1, "system_id_oui": [107, 0, 0]

  "heart_rate": { "bpm": 72, "contact_detected": true, "rr_jitter_ms": 0.0 },
  "pmd": { "pair_policy": "just-works", "ecg_source": "synthetic" }
}
```

`manufacturer_payload_hex` is lowercase hex (empty = no payload beyond the company id). `ecg_source` is `"synthetic"` or `{"file": "path"}` (text file, one integer µV per line @130 Hz, cycles; missing/unparseable file fails loudly at startup). `pair_policy` is `"just-works"` or `"disabled"`.
