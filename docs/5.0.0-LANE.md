# UBM 5.0 lane (`5.0.0`)

## Status

**Current, lane-scoped.** This document governs work in the UBM 5.0 lane
only. It does not change the 4.x release process in [`../RELEASE.md`](../RELEASE.md)
or the agent principles in [`../AGENTS.md`](../AGENTS.md).

**5.0 is not released.** The `5.0.0` branch is an unreleased development
lane. Nothing in this document claims otherwise.

## Purpose

The `5.0.0` branch is the integration base for UBM 5.0 work
(trackourhealth/bun-mono#1188). All 5.0 worker branches integrate there —
never directly to `main`.

## Branch rules

- Worker branches are named `codex/ubm5-*`.
- Worker branches set their base (and PR target) to `5.0.0`. Never `main`.
- Never merge the lane, or any lane worker branch, into `main`.
- Never create `v*` tags from the lane. Tags stay manual and `main`-sourced
  per [`../RELEASE.md`](../RELEASE.md); a lane tag could trigger the publish
  workflow (see below), so the prohibition is load-bearing, not cosmetic.
- Never publish from the lane. There is no lane publish path, and none is
  wanted: publication is on hold pending license/provenance review.

## CI coverage

Since the lane-scoped trigger change in
[`../.github/workflows/ci.yml`](../.github/workflows/ci.yml) (`U0`
CI-coverage slice), the lane gets the normal checks:

- pushes to the `5.0.0` branch run CI, as do pushes to `main` and
  `release/**`;
- pull requests whose base is `5.0.0` run CI, as do PRs targeting `main`,
  `agent/**`, and `release/**`.

Apple compile checks keep their existing gating (path filter on `main`
pushes, `ci:apple` label opt-in on PRs, or manual dispatch); the trigger
change did not widen them.

## Why the lane cannot accidentally publish

`.github/workflows/publish.yml` (read-only reference; this lane must not
modify it) only starts on pushed `v*.*.*` tags, and then requires, before
any initial publication, that the tag name equal the root `package.json`
version and that the tagged commit be exactly the current `main` commit.
The lane creates no `v*` tags and never merges to `main`, so pushing lane
work cannot satisfy either admission check. Publication additionally stays
on hold pending license/provenance review regardless of CI state.
