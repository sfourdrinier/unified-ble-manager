# UBM 5.0 R16 regression matrix

**Finding:** PR210 R16 (BLOCKER for qualification) — acceptance-layer
honesty: relabel synthetic legs, prove real bindings where the seam allows,
and disposition the required regression matrix with evidence, not intent.

**Scope note (packet G):** this matrix is authored on the solo 5.0.0 lane;
independent adversarial review is still pending. Every row states what was
real and what was mocked. Synthetic-seam passes never close physical,
background-lifetime, or radio gates.

**Evidence tiers used below:**

- `DEVICE` — executed on the emulator against the installed native module
  (no injected binding).
- `PACKED` — executed against the packed candidate (tarball/addon built
  from packed sources).
- `SEAM` — jest against a fake native binding (injected at the documented
  test seam; proves JS routing/ownership, not the native side).
- `CONTRACT` — unit/TCK proof of a contract primitive (parser, state
  machine, vector).
- `BLOCKED` — requires R03 core ops (connect/gatt/subscribe/counters) or a
  physical radio; sequenced, not waived.
- `OPEN` — seam-testable now; test not yet written.

## Relabeled synthetic legs (kept, honestly named)

- `scripts/ci/f01-factory-routing-proof.cjs` (Leg G, rewritten for
  PR210-55): the packed `lib` React Native factory is called with no
  `rustCore` option. It resolves the `UnifiedBleRustCore` TurboModule
  through the production binding and wire codec, drives a full journey, and
  refuses a foreign build (`protocol.incompatible`) and a missing module
  (`capability.unsupported`). The legacy `UnifiedBleProtocolControl` is
  stubbed to throw. SYNTHETIC: `react-native` is stubbed, the module is the
  deterministic wire double (pinned to the Rust golden vectors), and the Tauri
  leg replays a stub transport. Real-binding counterparts: the JVM exchange,
  the Apple harness and the `R01FACTORY` device leg.
- `scripts/ci/f01-packed-dispatch-proof.js`: legs A–E/G–J are real
  (pack/install/pinned-toolchain build/identity/compiles/ELF); leg F runs
  the real packed addon with staged inputs (see the hardware-boundary
  declaration in `bindings/napi/js/dispatch_roundtrip.cjs`, which prints
  the branch taken).

  with reasons; they never report synthetic passes as device receipts.
