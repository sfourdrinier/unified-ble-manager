# Expo SDK 57/58 support design and qualification status

floor `>=0.86.0`. SDK 57 is the checked-in `example-expo` baseline and maps to
React Native 0.86. SDK 58 is selected only in an isolated checkout and maps to
React Native 0.88 with React 19.3. The selector, dependency installer, and
Expo peer alignment must run in that order; generated manifest and lockfile
changes are restored after qualification. Expo Go remains unsupported.
